# 安全架构说明

## 系统边界

```text
uni-app 客户端
   │ X-Auth-Token + JSON/图片
   ▼
Spring Boot API
   ├── LoginInterceptor：公开 / 登录用户 / 管理员三级权限
   ├── QuerySpecParser：字段、排序、分页白名单
   ├── ImageStorageService：格式、尺寸、路径与文件名边界
   ├── MyBatis-Plus → MySQL：业务数据与服务端归属约束
   ├── Token/Reset Service → Redis：会话与短期验证码状态
   └── EasyDL Adapter ──HTTPS──> 百度 OAuth 与模型接口
```

浏览器或小程序只与本项目后端通信。外部模型的凭据、访问令牌、完整响应和内部错误不会返回客户端。

## 身份认证与授权

1. 登录时以 BCrypt 校验密码。
2. 后端用 `SecureRandom` 生成 32 字节不透明令牌，只向客户端返回一次。
3. Redis 键使用令牌的 SHA-256 摘要，避免缓存泄露时直接得到可用会话；会话 TTL 为 2 小时。
4. 拦截器解析会话后，把用户 ID 和用户组写入请求属性，业务层不信任客户端提交的身份字段。

权限分为：

- 公开：注册、登录、密码重置申请/确认、公开内容只读与静态资源。
- 登录用户：AI 诊断、图片上传、个人检测/咨询记录和互动操作。
- 管理员：用户与角色、导航/订单、文章、轮播、医院和科普等管理写操作。

个人检测、咨询及用户资料查询会在服务端增加所有者条件；普通用户不能通过改写 ID 访问或修改他人数据。

## 查询与数据库安全

通用查询不拼接客户端 SQL。`QuerySpecParser` 只接受实体注册表中存在的字段和有限比较操作，并拒绝：

- `sqlwhere` 或其他原始 SQL 参数；
- 未知字段、非法排序方向和无法解析的值；
- 超过 100 条的单页请求。

查询最终由 MyBatis-Plus Wrapper 参数化生成。数据库脚本只有结构定义，不包含账号、密码、手机号、邮箱、图片路径或业务数据。

## 图片上传边界

- 接受 PNG/JPEG，不能仅依赖扩展名或请求 `Content-Type`；文件必须可被 `ImageIO` 解码。
- 单文件最大 5 MiB，单边最大 8192 像素，总像素不超过 2500 万，降低大图解压耗尽内存的风险。
- 服务端重新编码并使用 UUID 文件名，拒绝客户端路径、任意文件名、符号链接和目录穿越。
- 读取接口只匹配 UUID 加 `.png`/`.jpg`，响应设置 `X-Content-Type-Options: nosniff`。
- 上传目录位于源码树之外并被 Git 忽略。

## EasyDL 推理流程

```text
已登录用户上传图片
  → 后端复用图片安全验证
  → 从 Redis 读取 EasyDL access token
  → 未命中时以服务端环境变量向百度 OAuth 换取并缓存
  → 调用配置的百度模型 HTTPS 地址
  → token 过期时清缓存并仅重试一次
  → 选择最高置信度结果
  → 只返回 {name, score}
```

HTTP 连接/读取超时分别为 3 秒和 15 秒。令牌缓存 TTL 为上游 `expires_in - 300 秒`；上游超时、不可用或响应异常统一转换为脱敏的 502。配置缺失时集成保持关闭并返回 503。令牌地址和模型地址必须为 `aip.baidubce.com` 的指定 HTTPS 路径，降低 SSRF 与凭据外传风险。

## 密码重置

密码重置默认关闭。启用后：验证码用安全随机数生成，Redis 只保存 HMAC 摘要；有效期 10 分钟、最多尝试 5 次、同邮箱发送冷却 60 秒、同来源每小时最多 5 次。申请接口始终返回一致文案，避免探测邮箱是否注册；验证成功后验证码一次性消费。

## 已知限制

- EasyDL 的真实可用性和识别质量依赖使用者自己的模型与有效凭据；仓库测试使用模拟 HTTP 响应。
- 项目是作品展示，不包含生产级网关、WAF、病毒扫描、对象存储、审计平台或高可用部署。
- 前端基于兼容性较老的 Vue 2/uni-app 构建链，应在隔离的 Node 环境中构建，并关注 Dependabot 告警；实际生产项目应规划升级。
- AI 结果不能替代医生诊断。
