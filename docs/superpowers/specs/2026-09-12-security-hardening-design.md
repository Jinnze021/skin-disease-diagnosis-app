# 皮肤病智诊影析小程序：校招安全公开版设计

## 1. 目标

在不修改原始毕业设计目录的前提下，创建一个适合校招公开展示的独立副本。公开版保留皮肤诊断、用户登录注册、在线咨询、论坛与知识内容等核心业务能力，移除公开仓库中的密钥、个人数据和高风险实现，使代码能够经受基础安全审查并便于面试官理解。

该版本是作品展示与本地演示项目，不作为真实医疗系统或互联网生产服务使用。

## 2. 范围与非目标

### 2.1 本次范围

- 将 EasyDL 认证和模型调用从前端迁移到 Spring Boot 后端。
- 使用环境变量管理数据库、Redis、邮箱和 EasyDL 配置。
- 使用 BCrypt 存储用户密码，移除硬编码 RSA 私钥和自定义前端密码加密。
- 让 Redis Token 拦截器真正执行认证，并区分公开、登录用户和管理员接口。
- 重构密码重置流程，避免验证码泄露、重放与无限发送。
- 消除可由 HTTP 参数控制的原始动态 SQL，限制查询、排序和聚合字段。
- 加固图片上传流程，防止路径穿越、类型伪造、超大文件和文件覆盖。
- 清理数据库导出中的用户数据、咨询数据、访问令牌和验证码。
- 清理生成目录，补充仓库级忽略规则、环境变量示例、安全说明和运行文档。
- 为核心安全行为增加自动化测试，并执行前后端构建和敏感信息扫描。

## 4. 总体架构

### 4.1 皮肤诊断数据流

1. 用户登录后在前端选择皮肤图片。
2. 前端以受限大小的图片请求后端诊断接口，不再请求百度 OAuth 接口。
3. 后端验证登录态、文件大小和图片内容。
4. EasyDL 客户端从环境变量读取 API Key 与 Secret Key。
5. 后端从 Redis 获取已缓存的百度 Access Token；缓存不存在或即将过期时重新获取。
6. 后端调用配置指定的 EasyDL 模型端点。
7. 后端只返回前端需要的标签、概率和提示信息，不转发认证数据或上游完整错误。

建议接口为 `POST /api/ai/skin-diagnosis`。密钥变量为 `EASYDL_API_KEY`、`EASYDL_SECRET_KEY` 和 `EASYDL_MODEL_URL`，真实值不写入代码、前端环境文件、测试或 README。

### 4.2 认证与授权

- 登录成功后生成高熵随机 Token，在 Redis 中保存最短必要的会话信息并设置两小时有效期。
- `LoginInterceptor` 处理跨域预检后，对非公开接口校验 `X-Auth-Token`，无效或过期时返回 HTTP 401 JSON，不进行页面重定向。
- 认证成功后把当前用户 ID 和角色写入请求属性，业务代码不再重复解析 Token。
- 明确维护公开接口清单：登录、注册、密码重置请求与确认、公开内容读取、静态资源。
- 用户资料、皮肤诊断、咨询、收藏和写操作需要登录；用户管理、权限配置和后台内容维护需要管理员角色。
- 用户相关接口使用专用响应对象，不返回密码、验证码、Redis Token 实体或内部状态字段。
- 跨域来源来自配置白名单，不反射任意 `Origin`；允许的方法和请求头保持最小集合。

### 4.3 密码与密码重置

- 注册、后台创建用户、修改密码和重置密码都通过同一个密码服务调用 BCrypt。
- 登录使用 BCrypt 校验，不再使用可逆 RSA 解密，也不保留服务器私钥。
- 密码重置分为“申请”和“确认”两个 POST 接口。
- 服务端使用安全随机数生成验证码，只在 Redis 中保存验证码摘要、邮箱、用途、尝试次数和过期时间。
- 发送接口不返回验证码和内部 Token，并对邮箱和来源地址设置冷却时间。
- 确认成功后原子删除验证码记录，保证一次性使用；错误次数达到上限后记录失效。
- 对不存在的账号返回相同的外部提示，减少账号枚举风险。

### 4.4 数据访问安全

- 删除 `BaseMapper.xml` 中 `${select}`、`${count}` 和 `${sql}` 的执行路径。
- 通用查询改用 MyBatis-Plus 参数化条件构造器；值始终作为绑定参数传入。
- 根据实体元数据建立允许字段集合，HTTP 参数只能选择实体真实字段。
- `field`、`order_by`、`group_by` 等标识符必须经过白名单验证；`sqlwhere` 和客户端原始 SQL 能力直接移除。
- 写操作只接受实体允许更新的字段，主键、密码、角色、审核状态等敏感字段由专用业务接口处理。
- 对公开内容查询保留必要的分页、精确查询、模糊查询和排序能力，不保留任意 SQL 表达能力。

### 4.5 图片上传安全

- 单文件上限调整为 5 MB，请求上限略高于单文件上限。
- 只接受 JPEG、PNG 和 WebP，并通过文件头或图片解码验证真实内容，不只依赖扩展名或浏览器 MIME。
- 服务端生成 UUID 文件名，忽略原始路径，只保留经过验证的扩展名。
- 上传目录来自 `APP_UPLOAD_DIR`，位于源码和 classpath 之外；保存前检查规范化目标路径仍在配置目录内。
- 诊断上传需要登录，不允许通过通用 CRUD 接口写入任意文件。
- 错误响应不返回服务器绝对路径、异常堆栈或上游凭证。

## 5. 配置、日志与依赖

- `application.yml` 只提供非敏感默认值；数据库密码、邮箱授权码和 EasyDL 密钥没有默认值。
- 提供 `.env.example` 或等价配置说明，变量值全部使用明显占位符。
- 生产配置关闭 MyBatis 原始 SQL 输出；日志不记录密码、验证码、完整 Token、邮箱正文或完整用户对象。
- 删除未使用且高风险的依赖；在保持 Java 8 兼容的前提下，将 Spring Boot、MySQL 驱动、MyBatis-Plus、Druid、POI 等升级到兼容的维护版本。
- 优先使用 Jackson 替换业务路径中的旧版 Fastjson；若一次性完全替换风险过高，至少升级到安全维护版本并限制使用范围。
- 增加依赖更新配置，使 GitHub 能持续提示后续漏洞。

## 7. 错误处理与兼容性

- 认证失败使用 401，权限不足使用 403，请求参数或文件不合法使用 400，上游模型不可用使用 502，未处理异常使用 500。
- 对外响应保持统一 JSON 结构，但不泄露堆栈、SQL、磁盘路径、Redis Key 或百度错误原文。
- 前端页面与核心功能保持不变；允许调整登录、重置密码和诊断接口调用方式。
- 如果旧数据使用明文密码，公开版不迁移真实数据；测试与本地演示通过新注册或安全种子数据验证 BCrypt 流程。

- SQL 查询字段、排序字段和原始 SQL 参数的白名单/拒绝测试。
- 上传空文件、超限文件、伪造扩展名、路径型文件名和有效图片的测试。
- EasyDL Token 缓存命中、过期刷新、上游错误脱敏的测试；测试使用模拟服务，不使用真实密钥。

### 8.2 构建与静态检查

- Maven 测试和打包通过。

## 10. 验收标准

安全公开版完成时必须满足：

1. 原始项目目录内容保持不变，并通过实施前后的文件清单与哈希对比验证。
2. 安全副本中不存在真实密钥、私钥、邮箱授权码、数据库密码、个人数据、历史 Token 和验证码。
3. 前端不再直接访问百度 OAuth 或携带 EasyDL Secret Key。
4. 受保护接口会拒绝匿名或无效 Token 请求。
5. 新密码采用 BCrypt，用户响应不包含密码。
6. 密码重置验证码不返回客户端，具备过期、限次和一次性使用机制。
7. HTTP 参数不能进入原始 SQL，也不能选择白名单外的列、排序或分组表达式。
8. 上传接口拒绝危险文件名、非图片和超限文件，并使用服务端随机文件名。
9. 后端测试与构建通过；前端构建或相关静态验证通过。
10. 新 Git 历史从已清理文件开始，且在本地复扫通过之前不发布到 GitHub。
